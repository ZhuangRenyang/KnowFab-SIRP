# AI 视频生成投喂包（不用拍、不用出镜）

> 用法：把「风格设定」放第一条，之后逐条生成 6~8 个 5 秒片段
> 推荐工具：**可灵 / 即梦 / Vidu**（中文提示词支持好）｜画幅 **9:16 竖屏**
> ⚠️ 每条提示词末尾都带「画面中不要出现任何文字」——**AI 生成的文字一定是乱码，必须后期加**

---

## 一、风格设定（每条 prompt 前面都带上这段）

```
真实工业纪实风格，电影感。深冷色调（青蓝 + 暖黄灯光对比），
轻微胶片颗粒，浅景深。手持轻微晃动，纪实摄影质感。
画面克制、不炫技，像工厂纪录片。9:16 竖屏。
画面中不要出现任何文字、字幕、logo、水印。
```

## 三、真实录屏（**不要用 AI 生成**）

产品界面必须用真实截图/录屏，AI 生成的界面一定会翻车。三个素材就够：

| 素材 | 从哪来 | 用法 |
|------|--------|------|
| 设备卡片（今日产量） | 系统截图 | 做成图片，加轻微缩放动效（Ken Burns） |
| 24 小时大屏 | 系统截图 / `docs/promo/shots/screen-full.png` | 同上，缓慢推近 |
| 库存 + 单据 | 系统截图 | 同上 |

**做法**：剪映里导入截图 → 每张 3 秒 → 加「缓慢放大」入场动画 → 就是动态画面，不用录屏。

## 五、配音（不用你开口）

剪映 → 文本朗读 → 选「**沉稳男声**」→ 语速 **0.9**。

配音稿就用上面的字幕，**但只念一半**（字幕全念会太密），建议念这些：

> 不改程序，不装数据库，不要团队，不要年费。
> 一个安装包，全厂的机器，全进 ERP。
> 还有一个 AI，早上自动给你写日报。
> 机器做一件，库存加一件，单据开一张。
> 让所有机器，都报产量。

（约 30 秒）

## 六、剪辑顺序（剪映，30 分钟）

```
0-5s    镜头1 老车间  → 字幕：不改程序 / 不装数据库
5-10s   镜头2 PLC     → 字幕：不要团队 / 不要年费
10-15s  镜头3 按按钮   → 字幕：一个安装包
15-25s  真实截图三连   → 字幕：全进 ERP / AI 写日报 / 产量算得清
25-30s  镜头4 数据流   → 字幕：库存加一件 单据开一张
30-35s  镜头5 仓库     → 字幕：新机老机都能接
35-40s  镜头6 工厂夜景 → 字幕：让所有机器都报产量
```

**音乐**：剪映搜「工业」「大气」「纪录片」，音量压到 25%。

## 七、三条避坑

| 坑 | 解法 |
|---|------|
| AI 生成文字乱码 | 提示词里写死「不要出现文字」，字幕全部后期加 |
| AI 生成的界面很假 | 产品演示只用真实截图，不用 AI |
| 画面太炫像游戏 | 提示词加「纪实」「克制」「不炫技」，别用「赛博朋克」「科幻」 |
