# 即梦 AI 生成方案（按分镜拆解）

> 脚本依据：`SHOOTING-BOARD-V2.md`（31 镜头）
> 结论先说：**AI 只能替代「人脸」和「实物/氛围」两类镜头，产品界面必须用真实截图。**
> 理由：AI 生成中文必乱码、生成软件界面必假，这两类会直接毁掉可信度。

---

## 一、31 个镜头怎么分

| 类型 | 分镜号 | 数量 | 用什么做 |
|------|--------|------|----------|
| **产品界面** | 8-18、22 | 12 | ❌ **必须真实截图/录屏** |
| **人脸说话** | 2-6、7、19、21、23-31 | 17 | ✅ 即梦数字人 / 或实拍 |
| **实物特写** | 1 | 1 | ✅ 即梦图生视频（用你的 PLC 照片） |
| **终端命令** | 20 | 1 | ❌ 真实录屏（AI 生成的终端全是乱码） |

**所以：AI 能覆盖的是「人」和「物」，覆盖不了「界面」。**

## 二、即梦提示词（可直接复制）

### ① 通用风格前缀（每条前面都加上）

```
真实工业纪实风格，电影感。深冷色调（青蓝 + 暖黄灯光对比），
轻微胶片颗粒，浅景深，手持轻微晃动。画面克制、不炫技。
9:16 竖屏。画面中不要出现任何文字、字幕、logo、水印。
```

---

### ② 实物镜头（分镜 1）

**做法：图生视频**（用你拍的 PLC 照片当首帧，效果比文生视频准得多）

```
一只手从画面下方把一个工业 PLC 控制器举起来，怼到镜头前，
控制器表面有使用痕迹和接线端子，背景是虚化的工作台。
镜头轻微推近，浅景深，侧上方打光。
真实工业质感，青蓝色调。
画面中不要出现任何文字、型号标识。
```

### ③ 氛围镜头（备用，剪辑时穿插）

**车间清晨**
```
清晨的老工厂车间，阳光从高窗斜射进来，光柱里飘着细微粉尘。
几台老旧机床静静运转，金属表面有油光和磨损痕迹。
镜头从远处缓慢推近、横移，浅景深，背景虚化。
```

**PLC 控制柜**
```
工业控制柜内部特写，一排模块上的指示灯有节奏地闪烁
（绿色常亮、黄色间歇闪）。密集的接线端子，线缆整齐束好。
镜头贴得很近，缓慢横移扫过模块表面，背景暗。
```

**按按钮（关键）**
```
一只工人的手（深灰工装袖口）食指按下机床面板上的绿色启动按钮，
按钮亮起。动作干脆，背景是虚化的机床和指示灯。
微距特写，慢动作，光线从侧上方打过来。
```

**成品仓库**
```
整洁的工厂成品仓库，多层货架上整齐码放着纸箱和金属零件箱，
顶部工业照明灯，地面有叉车轮胎印。
镜头缓慢向前推进，穿过货架通道，光线柔和偏冷。
```

**工厂夜景（收尾用）**
```
夜晚的工厂厂房外景，窗户透出暖黄色灯光，通风口有淡淡白汽升起，
天空是深蓝到黑的渐变。镜头缓慢后退拉远，整个厂区进入画面。
安静、有力量感。
```

**数据流（转场用）**
```
黑暗中，细密的蓝色光线从多台机器的轮廓中流出，
汇聚成一条流动的光带向上延伸，散成细碎光点。
极简克制，不要科幻炫光，像数据在静静流动。
深黑背景，青蓝色光线，缓慢上升运镜。
画面中不要出现任何文字、数字、图表。
```

### ④ 人脸镜头 → 用「数字人」，不要用文生视频

**为什么**：文生视频生成的人，口型对不上你说的台词，一眼假。
即梦的数字人（对口型）才能真正用。

**操作路径**：
1. 拍一段你自己的正面视频（10 秒，正对镜头，别动，不说话）→ 或用一张正脸照片
2. 即梦 → 数字人 → 上传素材 + 粘贴台词 → 生成
3. 把 17 段人脸镜头一次性批量生成，**同一张脸、同一套衣服**，剪辑时才连贯

**如果数字人效果不满意**：
直接**自己拍人脸**（手机架好，照分镜台词念）。17 段人脸，实拍 20 分钟就够——
**这比调 AI 参数快得多，而且真实感强十倍。**

## 三、产品界面：真实截图 + 自动动效

12 个界面镜头**一条都不能用 AI**。做法：

1. 系统里截 12 张图（设备列表、点表、卡片、库存、单据、报表、扫网段、大屏、报警、能耗、ERP、AI 对话）
2. 剪映里导入 → 每张 3~5 秒 → 加「缓慢放大」入场动画
3. 加箭头/高亮框指向关键数字

**这就是"动起来的截图"**，观众看起来和录屏差不多，但省了录屏的麻烦。

> 想要真实感更强，就用录屏（鼠标点两下），比截图更好。

## 四、即梦操作步骤（通用）

```
1. 打开即梦 → 视频生成
2. 模式选「文生视频」或「图生视频」（实物镜头优先用图生视频）
3. 比例选 9:16，时长选你能选的最长（5s 或 10s，剪辑时再裁）
4. 粘贴提示词（记得带风格前缀）
5. 生成 2~3 条，挑最好的一条
6. 下载，导入剪映
```

**别指望一次生成就对**——同一段提示词生成 3 次，挑一条能用的，这是常态。

## 五、两套混合方案（推荐第一套）

### 方案 A · AI 画面 + 真实界面（推荐）

```
人脸 17 段   → 数字人（或自己实拍，20 分钟）
实物 1 段    → 即梦图生视频（用 PLC 照片）
氛围 5 段    → 即梦文生视频（车间/控制柜/按钮/仓库/夜景）
界面 12 段   → 真实截图 + Ken Burns 动效
终端 1 段    → 真实录屏
```

**效果**：画面有电影感，界面是真的，可信度最高。

---

### 方案 B · 全 AI（先试水，接受降级）

```
全部镜头     → 即梦生成（人脸用数字人，界面用"抽象数据流"代替）
配音         → 剪映文本朗读（沉稳男声，语速 0.9）
字幕         → 剪映自动识别 + 校对
```

**代价**：产品演示变成了"数据流动画"，观众看不到真实界面 → **说服力掉一半**。

**适合**：先做一条试水，看数据反馈，再决定要不要投入实拍。

---

## 六、最重要的两句

> **AI 能画出工厂，但画不出你的界面。**
> 这条片子的可信度全在那 12 个真实界面上——AI 生成不了，也不该生成。

> **人脸别用文生视频，口型对不上，一眼假。**
> 要么数字人，要么自己拍。二选一，别用第三种。

## 七、如果先做 60 秒版（建议）

即梦按条计费，先做短的试水更划算。**只做这 8 段**：

| 段 | 镜头 | 用 AI 还是真实 |
|---|------|--------------|
| PLC 举起 | 1 | 即梦图生视频 |
| 四个「不」 | 2 | 数字人 |
| 一条命令 | 20 | 真实录屏 |
| 加设备/点表 | 8 | 真实截图 |
| 今日产量 | 9 | 真实截图 |
| 生产入库联动 | 11 | 真实截图 |
| 大屏 | 14 | 真实截图 |
| 收尾 | 31 | 数字人 |

**8 段，约 60 秒。** 生成 + 剪辑 2 小时能出片。
