# 内容方向重做：讲钱、讲人、不讲技术

> 上一版（挑战实验型）还是"技术人视角"——对普通老板和打工人依然无感。
> 真相：**观众不为"你的系统"停留，只为"我的钱""我的气""我的乐子"停留。**
> 所以下面三种内容，全部围绕 **利益 / 情绪 / 相关性**，技术只做背景板。

---

## 先认清一件事

| 你以为观众想看 | 观众其实想看 |
|----------------|-------------|
| 支持 Modbus TCP | **我厂里是不是也在偷偷亏钱** |
| 一条命令部署 | **这能不能让我少挨骂** |
| 24 小时产量曲线 | **老板会不会发现我在摸鱼** |
| 开源 AGPL | （划走） |

**唯一能让人停下来的公式**：
> **「这跟我有关」+「我没想到」+「有点爽/有点慌」**

---

## 方向一 · 设备拟人化（**最容易爆，制作成本最低**）

设备会说话、会发朋友圈、会吐槽。观众笑完，顺便记住了"哦，原来机器的事都能看见"。

### 脚本 1：《一号注塑机的朋友圈》

**形式**：手机竖屏，模仿微信朋友圈界面（剪映有模板，或自己截图拼）
**时长**：20 秒
**配音**：TTS 或自己念，用"委屈打工人"的语气

**画面与台词**：

```
【朋友圈卡片】
头像：注塑机照片
昵称：一号注塑机
正文：
今天干了 3012 件，比昨天多 210 件。
已经连续转 11 个小时了，没人来看我一眼。
能不能给加点润滑油，我关节疼。
配图：产量曲线截图

【评论区】
二号注塑机：兄弟你知足吧，我今天停机 4 次，已经被点名了
仓管老王：别叫，我叫你产多少你就产多少
老板：（已隐藏）
```

**配音**（委屈语气）：
> 「今天干了三千零一十二件，比昨天多两百一……已经连续转十一个小时了，没人来看我一眼。」

**结尾字幕**（一行，不要多）：
```
机器的事，其实都看得见
```

**为什么能爆**：
- 拟人化 = 天然好笑
- 老板看了会想「我厂里的机器现在什么状况？」→ **这就是转化点**
- 打工人看了会转发（"我们厂也这样"）

### 系列化（非常重要）

抖音吃系列，做成一季，培养追更：

| EP | 主题 |
|----|------|
| EP01 | 一号注塑机的朋友圈：我连续转了 11 小时 |
| EP02 | 三号机被点名：本周停机 5 次，累计 4 小时 |
| EP03 | 冲压机和 CNC 吵起来了：谁产量高 |
| EP04 | 电表的自白：你这个月电费，有一半是我贡献的 |
| EP05 | 老板深夜查手机：为什么二号机还在转？ |

**制作方法**（10 分钟一条）：
1. 系统里截设备卡片 / 产量曲线 / 停机记录
2. 剪映「图文成片」或自己做朋友圈样式
3. TTS 配音（选"委屈/年轻"音色）
4. 加搞笑 BGM（剪映搜"喜剧""无奈"）

## 方向二 · 算钱（**直接命中老板利益**）

开场一句话就是钱，老板立刻停下。

### 脚本 2：《这台机器，一年偷偷吃掉你 18 万》

**时长**：30 秒 | **形式**：数字动画 + 系统截图

```
0-4s   大字幕：一台机器
       小小地停着，一年吃掉你 18 万
       配音：「一台机器，一年能吃掉你十八万，你信吗？」

4-12s  字幕一条条蹦：
       每月停机 4 小时
       × 每小时 300 件
       × 每件 12 块
       = 一年 17.3 万
       配音：「一个月停四个小时，一小时少做三百件，一件十二块——一年十七万三。」

12-20s 画面：系统里的停机记录 / 设备状态（红黄绿）
       配音：「问题是，你根本不知道它什么时候停的、停了多久。」

20-28s 画面：设备卡片 → 停机原因 → 库存
       配音：「现在它停一次，我手机里就有记录：几点停的，停了多久，什么原因。」

28-30s 字幕：让老机器自己报产量
       配音：「想看的，搜 KnowFab-SIRP。」
```

**为什么有效**：老板不关心技术，但**关心 18 万**。算钱比讲功能有力一百倍。

> ⚠️ 数字要真实可推演（停机时长×产能×单价），不要瞎编，评论区会算。

## 方向三 · 抓内鬼 / 打脸（**冲突感最强，最容易引发讨论**）

账实不符、有人报假数、有人偷懒——这是工厂里最敏感也最有共鸣的话题。

### 脚本 3：《仓管说 5000 件，系统说 4700。老板信谁？》

**时长**：35 秒 | **形式**：对话字幕 + 屏幕对比

```
0-5s   字幕（大字）：
       仓管：我记得有 5000 件
       系统：4700

5-12s  配音：「月底盘点，仓管说五千，系统说四千七。差的这三百件，去哪了？」
       画面：EXCEL 表格 vs 系统库存页

12-22s 配音：「没人偷，也没人贪。就是每天少记几件，一个月就差了三百。」
       画面：生产入库单自动生成（一条条往下滚）

22-30s 配音：「现在机器每做一件，单子自己开一张，库存自己加一件。想差都难。」
       画面：按键 → 产量 +1 → 库存 +1

30-35s 字幕：账和货，终于对上了
```

**为什么能爆**：
- 有冲突（两个人说的不一样）
- 有悬念（300 件去哪了）
- 有共鸣（每个厂都对不上账）
- 评论区会吵起来（"我们厂差 3000 件"）→ **流量就来了**

## 三个方向的取舍

| 方向 | 目标受众 | 传播力 | 转化力 | 制作成本 | 建议 |
|------|---------|--------|--------|---------|------|
| **设备拟人化** | 打工人 + 老板 | ★★★★★ | ★★★ | 极低 | **先做这个，涨粉** |
| **算钱** | 老板 | ★★★ | ★★★★★ | 低 | 第二条做，转化 |
| **抓内鬼** | 老板 + 管理层 | ★★★★ | ★★★★ | 低 | 第三条做，制造讨论 |

**顺序建议**：拟人化涨粉 → 算钱转化 → 抓内鬼制造话题。**三条一轮，比一条精雕有用得多。**

---

## 「能不能火」的自检（发布前问自己四句）

1. **前 3 秒**：一个完全不关心工业的人，会不会想知道后面发生什么？
2. **有没有「跟我有关」**：钱、气、笑、慌，至少占一个
3. **能不能一句话转述**：如果观众跟同事说，他会怎么说？（"哎你看这个机器会发朋友圈"）
4. **有没有争议空间**：评论区能不能吵起来？（能吵 = 有流量）

四条里过不了两条，就重做。

---

## 最重要的一句

> **你的系统是"证据"，不是"主角"。**
> 主角永远是：老板的钱、仓管的账、打工人的摸鱼、机器的委屈。
> 系统只要在关键的一秒出现一次（产量在跳、单子在自动生成），就够了。

## 附：素材从哪来（都是现成的）

| 内容需要 | 系统里现成的东西 |
|---------|----------------|
| 设备产量曲线 | 设备详情 → 产量统计（日/月/年） |
| 停机记录 | 大屏「停机原因」/ 报警记录 |
| 库存对比 | 库存余额页、出入库单据 |
| 自动入库单 | 单据列表（生产入库，来源写着设备名） |
| 设备状态 | 监控页红黄绿、大屏设备网格 |
