# 三种「会被看完」的视频形式

> 前提：干讲功能的视频在抖音必死。观众不为你的功能停留，只为**悬念 / 反差 / 情绪**停留。
> 你手上的素材（一台十几年的 PLC、一只手、一块会跳数字的屏幕）本身就带戏剧性，
> 只是不能"介绍功能"，要"演一件事"。

---

## 为什么干讲没人看（先认这件事）

| 干讲 | 观众内心 |
|------|---------|
| 「支持 Modbus TCP / OPC UA / 485」 | 关我什么事 |
| 「一条命令部署，自带数据库」 | 这是什么意思 |
| 「开源 AGPL 商业授权」 | 划走 |

**能让人停留的只有三种东西**：
1. **悬念**：接下来会怎样？能不能成？
2. **反差**：这么旧的东西 / 这么简单的方法，居然行？
3. **情绪**：这事我也遇到过，太气了 / 太爽了

---

## 形式一 · 挑战实验型（**首推**，你手上的素材完全够）

**主题**：「给一台十几年前的 PLC 装上大脑，第一天」

**为什么能看**：全程是"能不能成"的悬念。观众不是来听功能的，是来看**结果**的。
成了的那一刻，比讲十遍功能都有说服力。

### 封面 / 标题

- 封面：PLC 实物 + 大字「**2010 年的 PLC，还能救吗**」
- 标题：`家里翻出一台 2010 年的 PLC，我让它自己报产量了`

### 脚本（30 秒，第一人称，不用出镜）

| 时间 | 画面 | 字幕（大字） | 旁白 |
|------|------|------------|------|
| 0-3s | PLC 拿在手里翻看，镜头怼近型号丝印 | **2010 年的 PLC**<br>厂里早就不用了 | 「这台 PLC 是 2010 年的，厂里淘汰下来一直扔着。」 |
| 3-7s | 网线插入 PLC 网口特写（动作要慢、清楚） | 插一根网线<br>程序一行不改 | 「我给它插一根网线。程序一行都不改。」 |
| 7-12s | 屏幕：设备在线、寄存器读数出现 | 它被认出来了 | 「系统把它认出来了，寄存器里的数直接读出来。」 |
| 12-20s | **手指按下按钮 → 屏幕产量 +1**（按 3 次，剪成连跳） | 按一下<br>产量加一件 | （不说话，让 BGM 起来） |
| 20-26s | 切库存页：数字自动 +3；切入库单列表 | 库存自动加<br>单子自动开 | 「按三下，库存多三件，入库单也自己开了。」 |
| 26-30s | 黑底 + 定位语 | **让老机器自己报产量**<br>KnowFab-SIRP · GitHub/Gitee 可搜 | 「这项目我开源了，搜 KnowFab-SIRP。」 |

**关键**：12-20 秒那段**不要旁白**，只留按键声 + BGM 鼓点。让画面自己说话。

## 形式二 · 痛点故事型（适合口播，但必须"讲故事"不是"讲功能"）

**主题**：「月底对账，账和货差 300 件，谁背锅？」

### 脚本（40 秒）

| 时间 | 内容 |
|------|------|
| 0-5s | 字幕：「工厂里最扯的一件事」→「账和货，永远差几百件」 |
| 5-15s | 旁白：「月底盘点，账上说有 5000 件，实际数出来 4700。差的 300 件去哪了？没人知道。老板问仓管，仓管问车间，车间说机器一直在转。」 |
| 15-25s | 画面：设备卡片产量 → 库存页（同屏对比）<br>旁白：「其实就差一件事：产量和库存，得是同一本账。」 |
| 25-35s | 按键 → 产量 +1 → 库存 +1 → 单据自动生成<br>旁白：「机器每做一件，库存自己加一件，单据自己开一张。对账？不用对了。」 |
| 35-40s | 定位语 + 搜项目名 |

**为什么能看**：前 5 秒就给了"我也遇到过"的情绪共鸣，观众会想知道"怎么解决的"。

## 形式三 · 反差对比型（信息量最大，适合 B 站）

**主题**：「同一台机器，人工统计 vs 系统统计」

### 画面：左右分屏

| 左半屏 | 右半屏 |
|--------|--------|
| 纸笔 / Excel（示意即可） | 系统屏幕 |
| 字幕：「人工：班组长记，下班交表」 | 字幕：「系统：按一下就记，不用交表」 |
| 字幕：「月底汇总，2 小时」 | 字幕：「随时看，0 秒」 |
| 字幕：「误差 ±5%」 | 字幕：「误差 0」 |

**旁白**：「同一个车间，两种活法。左边是现在的样子，右边是接上系统之后。」

> 这个形式不用实物，纯屏幕 + 分屏，**剪辑成本最低**，适合发 B 站/视频号（那边人愿意看对比）。

---

## 三种形式的取舍

| 形式 | 拍摄难度 | 抖音适配 | 用在哪 |
|------|---------|---------|--------|
| **① 挑战实验** | 低（PLC + 手 + 屏幕） | ★★★★★ | 抖音首条（推荐先拍这个） |
| ② 痛点故事 | 中（要口播） | ★★★★ | 抖音第二条 |
| ③ 反差对比 | 最低（纯屏幕） | ★★★ | B站/视频号 |

**建议节奏**：先拍 ①（最容易、最有悬念）→ 有反馈了再拍 ② → ③ 作为补充素材。

---

## 「不无聊」的六个硬指标（剪辑时逐条对照）

1. **前 3 秒必须有实物或冲突** —— 不能是黑底 logo
2. **字幕比旁白重要** —— 抖音一半人静音看，字幕要大要少（一行 ≤ 10 字）
3. **每 3 秒换一次画面** —— 同一画面超过 3 秒必掉人
4. **数字要跳给人看** —— 产量跳、库存跳，是唯一的"爽点"，别用静态截图
5. **留白给声音** —— 按键那一下不要配旁白，让"咔"的声音和数字跳同步
6. **别自我介绍** —— 前 20 秒不要说"我是做 XX 的"，先给结果

---

## 一句话总结

> **别介绍产品，演一件事。**
> 观众不关心你做了什么，只关心「这台老机器到底能不能自己报产量」。
> 答案是"能"的时候，产品介绍自然就完成了。
