# 五、文案（发布时用）

## 标题（三选一）

1. `不改程序、不装数据库、不要团队、不要年费：一个电工写的工厂系统`
2. `机器做一件，账上多一件：开源免费的工厂系统`
3. `一个人做的工厂系统，能接 PLC、能进库存、还能问 AI`

## 正文

```
不改 PLC 程序，不装数据库，不要团队，不要年费。
一个安装包，全厂的机器，全进 ERP。

这是我做的 KnowFab SIRP（知造）——AI 智慧工厂管理系统。

设备接进来，产量自己算（PLC 寄存器几十万也不用清零），
库存自动加，入库单自动开，报表一键导 Excel。

还有车间大屏、报警码翻译、分时电价与基本电费对比、
采购销售库存财务报表、以及能查数据的 AI。

开源自用免费，一条命令就能装，不用装 Java、不用装数据库、不用 Docker。
数据全在自己电脑里，断网也能用。
```

## 置顶评论

```
开源免费，自己厂里用不花钱；商业用途（闭源卖 / 做 SaaS）需要授权。
安装命令在主页，不用装 Java / 数据库 / Docker，一条命令跑起来。
接不上的设备也可以发我型号，我帮你看参数怎么配。
```
