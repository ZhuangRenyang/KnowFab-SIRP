## 【20-32s · 这是什么】

我是做电气的，后来自学写代码。
这套系统叫 **KnowFab SIRP**，中文叫**知造**——AI 智慧工厂管理系统。

从 MRP、MRP II、ERP 走过来，我叫它 SIRP：**会算账，也会说话的那种**。

…

## 【32-70s · 能干什么 · 一条链讲完，边讲边演示】

（切屏幕）

先说主线：**机器做一件，账上多一件。**

具体是这么一条链：

- 设备接进来（Modbus、OPC UA、485 都行，**新机老机都能接**，没网口加个几十块模块）
- 产量自己算（**PLC 寄存器里几十万也不用清零，按增量算**）
- 库存自动加（每做一件，成品仓加一件）
- 入库单自动开（来源写着设备名，仓管不用抄）
- 报表一键导 Excel

…

## 【70-105s · 六个板块，一段一个】

（快速切页面，每页 3 秒）

**设备监控**：加设备不用写代码，选模板填 IP。扫网段能自己把设备找出来，连寄存器地址都给你探好。

**车间大屏**：挂墙上就能用，纯网页。二十四小时产量曲线，出了故障原因顶在最上面。还有一块**独立故障屏**，维修工站前面能看全。

**报警**：伺服报警码它翻成中文——「过载，检查机械负载」，还带处理建议。台达、三菱内置，加品牌就是加个文件。

**能耗**：峰谷平分时电价，算得出哪台机器费电。还能算**基本电费**——按容量交和按需量交，哪种划算，两种价格摆一起给你看。

**ERP**：采购、销售、库存、财务、产线、报表都有。产线上的成品自动进成品仓。

**AI**：不是聊天框。它接了七个查询工具——库存、产线产量、设备状态、报警、采购、销售、应收应付，你问它，它自己去查。而且**分权限**，班组长查不到财务。

## 【105-140s · 开源免费 + 一键安装（这段是重点）】

（切终端，或者只讲）

这套东西**开源，自己用不花钱**。代码全在 GitHub 和 Gitee 上，AGPL 协议。

装起来就一条命令：

**Windows**：一行 PowerShell，复制粘贴回车。
**Linux**：一行 curl，同样。

**不用装 Java，不用装数据库，不用 Docker。** 安装包自带运行环境，跑在一台普通电脑上就行。

断网也能用，数据全在你自己的机器里，不出厂。

> 商业用途（闭源卖、做 SaaS）需要授权，自己厂里用、自己改，都不用。

…

## 【140-190s · 未来要做什么（让人看到它在长）】

（回人脸）

这半年我把它从「能看数据」做到了「能算账、能对话」。接下来三件事：

**第一，能耗往里做。**现在能看全厂电费，下一步按车间、按产线分开算，还能对国标能效——同行用多少电，你在什么位置。

**第二，OEE 做完整。**现在有可用率和状态时长，加上计划产量和不良数，就是完整的 OEE。

**第三，AI 再往深走。**现在是查数据，下一步是出报表——你说「给我这个月的产量报表」，它自己生成。

还有一件事一直在做：**加更多的设备驱动**。三菱、汇川、台达、欧姆龙，一台一台加。

…

## 【190-210s · 收尾】

（放下 PLC）

我做了这么久，最想说的是这句：

**工厂里最贵的不是机器，是你不知道它在干什么。**

那些十几年的老设备，还能再干十年——只要有人愿意把它的数据接出来。

**知造 SIRP，让所有机器都报产量。**
开源免费，一条命令，你自己电脑上就能跑。
