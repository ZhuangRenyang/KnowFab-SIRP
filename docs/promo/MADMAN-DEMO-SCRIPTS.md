# 三机位完整脚本：人脸 + PLC 实物 + 屏幕演示

> 形式：**出镜口播（疯癫） + PLC 实物特写 + 系统屏幕演示**，剪成一条 70 秒的完整片。
> 核心节奏：**我说结论 → 拿实物证明 → 切屏幕看效果**，每 3~5 秒换一次机位。
> 你只需要：一部手机、一个手机支架、一个录屏软件。

---

## 一、三机位分工

| 机位 | 拍什么 | 怎么拍 | 用途 |
|------|--------|--------|------|
| **A · 人脸** | 你对着镜头说话 | 手机架正面，竖屏，离脸 40cm，眼睛看镜头 | 观点、结论、情绪 |
| **B · 屏幕** | 系统界面操作 | 电脑录屏（OBS / 剪映录屏），1920×1080 | 演示效果 |
| **C · 实物** | PLC、网线、按钮、手指 | 手机手持怼近，背景虚化 | 证明"是真的" |

**关键**：三个机位**分开录**，最后按脚本串起来。不要一次拍完（会乱、会卡）。

---

## 二、拍摄顺序（先录哪个省事）

```
第 1 步：录 B 屏幕（最花时间，先做）
   → 打开系统，逐个页面操作一遍，边操作边留停顿（方便后期剪）
第 2 步：录 C 实物（5 分钟）
   → PLC 翻看、插网线、按键、指示灯，每个动作录 15 秒
第 3 步：录 A 人脸（最后录）
   → 此时你已经把前两步看过一遍，说台词最有感觉
```

## 四、屏幕演示前必做的准备（否则画面会很难看）

| 准备项 | 怎么做 |
|--------|--------|
| 浏览器缩放 | **125%**（数字才够大，手机上看清） |
| 窗口 | 只留系统一个标签页，F11 全屏 |
| 设备卡片 | 提前按几下按钮，让「今日产量」有基数（别从 0 开始） |
| 库存页 | 停在「成品一仓 · P-001」那行，**别看错行** |
| 单据页 | 先确认最新一张是「生产入库」，来源写着设备名 |
| 大屏页 | `screen.html` 单独开一个窗口，录 10 秒备用 |
| 鼠标 | 录屏时**慢一点**，每个点击停留 0.5 秒（观众要看清） |
| 通知 | 全部关掉（微信、系统弹窗） |

## 五、剪辑流程（剪映，30 分钟）

1. **新建项目 → 导入**：A 人脸片段、B 录屏、C 实物，全部拖进媒体区
2. **按分镜表排时间轴**：先铺 A 的台词，再把 B/C 按时间点插进去
3. **切换节奏检查**：任何一个画面**超过 4 秒没变化就切一刀**
4. **加字幕**：系统识别 → 逐条校对（工业词容易错：寄存器、Modbus、注塑机）
5. **字幕样式**：白色粗体 + 黑边，或黄底黑字，字号拉大，一行 ≤ 10 字
6. **加音效**：
   - 按键"咔"（重点！用它盖住切换点）
   - 数字跳动的"叮"
   - 字幕出现的"打字声"
7. **配乐**：选"紧张/燃"类，音量压到人声的 25%
8. **开头 2 秒**：把最狠那句提到最前面（哪怕它原本在中间）

## 六、口播配合演示的 4 个技巧

1. **手指引导**：说"你看这里"时，**手要伸进画面指向屏幕**（比鼠标点更有说服力）
2. **先给结果再解释**：先说"它自己会开单"，再演示（观众的注意力只有 3 秒）
3. **让数字有变化**：所有演示必须"从 A 变到 B"，静态画面等于没演示
4. **失误别剪掉**：PLC 没连上、点错页面——**留着**，观众反而更信你（"这是真机不是录好的"）
