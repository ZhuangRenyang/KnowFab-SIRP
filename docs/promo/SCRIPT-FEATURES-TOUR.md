# 功能走查脚本（纯功能版）

## 一、设备接入（40 秒）

**① 设备列表**
所有设备在这儿。在线、离线、今日产量，一眼看完。

**② 加设备**
加设备不用写代码。选个模板，填 IP 和端口，保存。

**③ 点表**
点表就是告诉系统：哪个寄存器是产量、哪个是运行状态、哪个是报警、哪个是电表读数。
一段 JSON，改完就生效，不用重启。

**④ 网段扫描**
不知道设备 IP？扫一遍网段。扫到设备之后，它会自动读寄存器，哪个地址在变，一眼看出来，直接生成点表。

**⑤ 协议支持**
Modbus TCP、Modbus RTU、485 转网口、OPC UA。
老设备没网口，加个几十块的转换模块就行。

…

---

## 二、设备监控（20 秒）

**⑥ 设备卡片**
每台设备一张卡片：运行状态、今日产量、累计产量、最后通讯时间、错误信息。

**⑦ 状态与报警**
运行、待机、停机、报警，四种状态分开算时长。

**⑧ 点位详情**
点开任何一台，能看到它所有点位的实时值，还有历史曲线。

…

---

## 三、产量统计（30 秒）

**⑨ 今日 / 本月 / 今年**
三个数字同时给。PLC 寄存器里几十万也不用清零，按增量算。

**⑩ 小时产量**
每小时的产量和状态时长——运行多久、待机多久、停机多久、报警多久。

**⑪ 日表 / 月表 / 年表**
日表看今天 24 小时，月表看这个月每一天，年表看十二个月。

**⑫ 可用率**
每台设备的可用率，用有效采集时长除以运行时长。

**⑬ 产量目标**
给设备设日目标，卡片上直接显示完成率。

…

---

## 四、报警（35 秒）

**⑭ 报警规则**
四种规则：设备离线、报警信号、工作时间停机超时、数值超阈值。
自己加，自己改。

**⑮ 报警列表**
没处理的、已确认的、已恢复的，分开列。

**⑯ 报警码翻译**
伺服报警码直接翻成中文：「过载，检查机械负载」。
台达、三菱内置，加品牌就是加一个文件。

**⑰ AI 故障建议**
报警的时候，AI 会给出原因判断和处理建议，维修工不用翻手册。

**⑱ 确认与记录**
谁确认的、什么时候确认的，都留着。

…

---

## 五、大屏（30 秒）

**⑲ 车间大屏**
一个网页，挂墙上就能用，不用登录。
二十四小时完整产量轴，哪个小时掉了，看得见。

**⑳ 故障置顶**
出了故障，原因和处理建议直接顶在最上面。

**㉑ 双视图切换**
「停机原因」和「故障看板」两个视图，点一下切换。
故障多的时候自动轮播。

**㉒ 独立故障屏**
另有一块专门的故障屏，整屏铺维修卡，一次显示四台，超过四台自动轮播。
维修工站在前面能看全。

**㉓ 大屏免登录**
接口只出聚合数字和设备名，不暴露点表和密钥。

…

---

## 六、能耗（35 秒）

**㉔ 分时电价**
峰、谷、平，每个时段单价自己配。

**㉕ 电量统计**
累计电量寄存器按增量算 kWh，读数变小会识别成重置，不会算成负数。

**㉖ 设备能耗对比**
哪台机器费电，一眼看出来。

**㉗ 基本电费两种算法**
按容量交，还是按需量交——两种价格摆在一起，哪种划算一目了然。

**㉘ 合同需量余量**
离合同需量还剩多少 kW，快到线了会报警。

…

---

## 七、ERP（40 秒）

**㉙ 基础资料**
产品、物料、仓库、往来单位。

**㉚ 库存余额**
每个 SKU 在每个仓的现存数量。库存是流水累计出来的。

**㉛ 出入库单据**
入库、出库、盘点调整，每笔都有单据。

**㉜ 生产入库联动**
机器做一件，库存加一件，生产入库单自己开一张，来源写着设备名。

**㉝ 采购**
采购订单、明细、收货。

**㉞ 销售**
销售订单、明细、发货。

**㉟ 财务**
应收应付、收付款、账龄。

**㊱ 产线**
产线、工位、设备归属，成品计数可以指定某台设备。

**㊲ 经营报表**
一张报表看完经营情况，导出 Excel。

**㊳ 销售查询**
销售角色只能看库存和可承诺量，看不到成本。

…

---

## 八、AI（30 秒）

**㊴ 对话查数据**
不是聊天框。它接了七个查询工具：库存、产线产量、设备状态、报警、采购、销售、应收应付。
你问它，它自己调工具去查。

**㊵ 按角色授权**
班组长只能查产量、设备、报警；财务数据要经理以上。
模型越权调用会被拒绝。

**㊶ AI 早报**
每天定时生成一份，昨天的产量、停机、电费，写成一段人话。数据本地算，AI 只负责润色。

**㊷ 经营解读**
经营概况页一键生成解读。

…

---

## 九、系统（25 秒）

**㊸ 用户权限**
管理员、车间主任、班组长、销售，四级。
写设备只有管理员和主任能操作。

**㊹ 在线升级**
页面上检查更新，下载，校验签名，重启生效。
Gitee 连不上自动切 GitHub。

**㊺ 开放接口**
`/open/v1` 带 API Key，可以对接自己的系统。

**㊻ 远程控制**
继电器、启停这些开关量能下发。
默认关闭，点位级授权，每次下发记审计日志。

# 拍摄建议

| 项 | 说明 |
|---|------|
| 画面 | 全程屏幕录制，只有开头结尾露脸 |
| 节奏 | 每个功能 2~3 秒画面，**不要停太久**（这是走查，不是教程） |
| 字幕 | 功能名放左上角，一句话说明在下 |
| 时长 | 3 分钟；抖音版删到 60 秒（只留 ①③⑨⑲㉜㊴ 六条） |

**六个必留的功能**（抖音 60 秒版）：
1. 点表配置（加设备不用写代码）
2. 网段扫描（自动找设备）
3. 今日产量（不用清零 PLC）
4. 大屏（24 小时 + 故障置顶）
5. 生产入库联动（机器做一件，库存加一件）
6. AI 查数据（七个工具）
