# 演示视频脚本（照着拍就行）

> 两个版本：**A 真机版**（王炸，用家里的 PLC）和 **B 演示环境版**（兜底/补充）。
> 建议 A 为主、B 素材穿插。B 站主片 4 分钟，抖音/视频号剪 60 秒短版。

## 版本 A：真机版《给一台真 PLC 装上自动报产量系统》

### 开拍前的准备（PLC 侧）

1. **确认型号**（西门子 SMART / 三菱 / 汇川 / 信捷……）发我，我给你对应的开 Modbus 从站步骤
2. PLC 里写个最小程序（10 分钟）：**按一下输入点 X0，数据寄存器 D0 加 1**
   ——这就是"行程开关计件"的完美复刻：按一下 = 产一件
3. PLC 接入系统两条路任选：
   - 带网口且支持 Modbus TCP 从站 → 网线直连（路径 A）
   - 只有 485 串口 → 485 转网口小盒子（路径 B，顺便演示了"老设备怎么接"）
4. 录屏工具：OBS（免费），录屏 1920×1080；手机竖拍接线特写

### 拍摄避坑

- 录屏分辨率 1920×1080，**浏览器缩放 100%**（文字才够大）；手机拍接线用横屏
- 全程开字幕（剪映自动识别 + 手工校对，工业词要多校）
- 镜头 5 是全片灵魂，多拍几条选最顺的；屏幕上产量数字要**够大**（可临时把浏览器缩放 125%）
- 背景音乐选剪映里"科技感"类，音量压到人声的 30%
- B 站封面：镜头 5 的分屏画面 + 大字"按一下 产量+1"
