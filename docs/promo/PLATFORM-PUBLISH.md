# 多平台发布矩阵（合规版）

> 前提约束：**抖音禁止在视频/文案/评论出现 QQ 号、微信号、二维码等第三方社交平台引流**。
> 所以「群号 + 二维码」不是删掉，而是**换个平台落点**，各平台各用合规的方式。

---

## 一、平台分工与合规边界

| 平台 | 能不能放群号/二维码 | 怎么引导 | 定位 |
|------|--------------------|---------|------|
| **抖音** | ❌ 不放 | 视频口播「**主页有安装包**」/ 文案「**私信发你**」/ 置顶评论「**扣 1**」 | 曝光、涨粉 |
| **B 站** | ⚠️ 简介可放**仓库链接**，群号尽量不放 | 简介放 GitHub/Gitee 链接，置顶评论放仓库链接 | 长尾、信任、技术观众 |
| **视频号** | ⚠️ 只能放**微信**相关，不能放 QQ | 引导公众号（视频号可关联公众号） | 老板人群、私域 |
| **公众号** | ✅ 可以放群二维码 | 文末放群二维码 + 仓库链接 | 长文、沉淀、转化 |
| **GitHub / Gitee** | ✅ 随便放 | README 已内嵌二维码 | **落地页（主入口）** |
| **QQ 群** | ✅ 就是这里 | 群文件 + 群公告 | 留存、答疑、案例 |

---

## 二、流量怎么走（一条闭环）

```
        抖音（曝光，量大）
              │  私信 / 主页
              ▼
    ┌──────────────────────┐
    │  GitHub / Gitee 仓库  │  ← 二维码、群号、全部下载都在这
    └──────────────────────┘
              │
              ▼
         QQ 群 1132864448    ← 答疑、案例、群文件
              │
              ▼
      真实客户 + 案例反哺文档
```

**关键**：二维码只需要放在**仓库 README**（已做好）和**公众号/B 站简介**这类允许的地方。
抖音那边一个数字都不出现，流量照样能接住——靠私信。

## 三、抖音文案模板（合规版，直接复制）

**标题**（选一）：
- `让跑了十几年的老 PLC 自己报产量`
- `不改一行 PLC 程序，老机器的产量上屏了`

**正文**：
```
接了台十年前的老 PLC，一根网线，没改一行程序，
产量、故障、库存全上屏了。

不用 Docker、不用装数据库、不联网也能用。

想要安装包的，评论区扣「1」，或者私信我发你。
#工业自动化 #MES #PLC #制造业数字化 #国产工业软件
```

**置顶评论（自己写）**：
```
源码 + 一键安装包 + 接入清单：GitHub 和 Gitee 搜 KnowFab-SIRP。
接不上的设备也可以发我型号，我帮你看参数怎么配。
```

**主页简介**（不出现任何第三方社交平台标识）：
```
知造 KnowFab-SIRP · 让所有机器都报产量
开源 · 一键安装 · 数据不出厂
安装包 / 文档 / 源码 ↓ 主页链接
```

> ⚠️ 抖音主页简介同样会被识别「引流到第三方平台」并折叠/限流。
> **最稳的做法**：简介只写定位语，把仓库链接放在**私信自动回复**里，
> 或在视频里明确说「**主页第一条评论有链接**」。

## 四、私信自动回复话术（关键承接点）

抖音私信量大的时候手打不过来，用「抖音私信自动回复」或人工模板：

```
你好！安装包和文档在仓库里，GitHub / Gitee 搜 KnowFab-SIRP 就能找到：
  github.com/ZhuangRenyang/KnowFab-SIRP
  gitee.com/ZhuangRenyang/KnowFab-SIRP

Windows 一条命令：
  curl -fsSL https://gitee.com/ZhuangRenyang/KnowFab-SIRP/raw/main/tools/install.sh | bash

群里（QQ 1132864448）有接入答疑和群文件：
  github.com/ZhuangRenyang/KnowFab-SIRP 里 README 底部有二维码，扫码进群。
```

> 这条回复本身把 QQ 号放在**文字里**，不在视频/评论中——合规风险低。
> 若仍担心，先只发仓库链接（仓库 README 里有二维码），更保险。

## 五、每条视频的落地动作（发布后 10 分钟内做完）

1. **置顶自己的评论**（仓库链接 + 一句钩子）
2. **把视频同步发到 QQ 群**（配一句引导：谁接了同款机器，报个型号）
3. **把视频同步 B 站**（简介放仓库链接，那边人群会看技术细节）
4. **把视频同步视频号 + 公众号**（公众号图文里放群二维码）
5. **仓库 README 里加一行「视频演示」链接**（指向视频页面）

---

## 六、两条纪律

1. **抖音侧：不出现任何第三方社交平台标识**（QQ号、微信号、二维码、"加V"）
2. **仓库侧：所有引流入口都放这里**——README 是唯一落地页，二维码已内嵌

这样做的好处是：**平台规则干净 → 不限流**；而用户从私信/简介点进仓库，
看到的是**代码 + 文档 + 真实视频**，信任度比群号高得多。
