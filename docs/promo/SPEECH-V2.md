## 三、一条业务链

【切屏幕】

先说主线：**机器做一件，账上多一件。**

…

设备接进来，Modbus、OPC UA、485 都行。**新机老机都能接**，没网口加个几十块模块。

…

产量自己算。PLC 寄存器里几十万也不用清零——**按增量算。**

…

每做一件，库存自动加一件。

…

入库单自己开一张，来源写着设备名。**仓管不用抄。**

…

报表一键导 Excel。

…

## 四、六个板块

【快速切页面，每段 5 秒左右】

**设备**：加设备不用写代码，扫网段能自己把设备找出来，寄存器地址都给你探好。

…

**大屏**：挂墙上就能用，纯网页。二十四小时曲线，故障原因顶在最上面。

…

**报警**：伺服报警码翻成中文——「过载，检查机械负载」，还带处理建议。

…

**能耗**：峰谷平分时电价。还能算基本电费——**按容量交还是按需量交，哪种划算，两种价格摆一起给你看。**

…

**ERP**：采购、销售、库存、财务、产线、报表都有。产线上的成品自动进成品仓。

…

**AI**：不是聊天框。七个查询工具，你问它，它自己去查。**还分权限。**

…

## 五、开源免费 + 一键安装

【回人脸】

这套东西**开源，自己用不花钱**。代码全在 GitHub 和 Gitee 上。

…

【切终端】

装起来就一条命令。Windows 一行 PowerShell，Linux 一行 curl。

…

【回人脸，连着说，中间不要停】

**不用装 Java，不用装数据库，不用 Docker。**

…

断网也能用，数据全在你自己的机器里，不出厂。

…

商业用途需要授权——自己厂里用、自己改，都不用。

…

## 六、未来三件事

【语速放慢，像聊天】

这半年我把它从「能看数据」做到了「能算账、能对话」。接下来三件事。

…

**第一，能耗往里做。**
现在能看全厂电费，下一步按车间、按产线分开算，还能对国标能效——同行用多少电，你在什么位置。

…

**第二，OEE 做完整。**
现在有可用率和状态时长，加上计划产量和不良数，就是完整的 OEE。

…

**第三，AI 再往深走。**
现在是查数据，下一步是出报表——你说「给我这个月的产量报表」，它自己生成。

…

还有一件一直在做：**加更多设备驱动**。三菱、汇川、台达、欧姆龙，一台一台加。

…

…
