# S7-200 SMART 接入清单（演示视频 PLC 侧准备）

> 目标：按一下输入按钮 → V 区计数 +1 → 知造 SIRP 产量实时 +1 → 自动生成入库单。
> 先确认一件事：**CPU 固件版本**（Micro/WIN SMART 里 PLC → 信息 可看）：
> - **固件 ≥ V2.2** → 走**方案 1：Modbus TCP**，网线直连，演示最干净（推荐）
> - **固件 < V2.2** → 走**方案 2：Modbus RTU 从站** + 485 转网口盒子（顺便演示了老设备怎么接）

## 术语对照（电工视角 → 本系统）

| 你熟悉的叫法 | S7-200 SMART 实际 | 本系统点表 |
|---|---|---|
| 输入点 X0 | **I0.0** | （不采集，只接线） |
| 数据寄存器 D0 | **VW0**（V 区一个字） | `funCode=3`（读保持寄存器）、`address=0`、`dt=uint16`、`role=count` |
| 站号 | MBUS 从站地址 | TCP：unitId；RTU：MBUS_INIT 的 Addr |

## 最小程序（10 分钟，两种方案通用）

梯形图两个网络（STL 视图直接粘）：

```
// 网络1：上电清零一次
LD SM0.1
MOVW +0, VW0

// 网络2：I0.0 上升沿 → 计数 +1（EU 是上升沿微分，按一下加一次）
LD I0.0
EU
INCW VW0
```

I0.0 接一个按钮（PLC 自带输入点，按钮公共端接 L+/M 按你 CPU 的输入型式来——你电工，这步你比我熟）。

## 方案 1：Modbus TCP（固件 ≥ V2.2，推荐）

1. **网络**：PLC 网口接路由器/交换机；电脑设同网段
   （SMART 出厂 IP 通常是 `192.168.2.1`，电脑可设 `192.168.2.100`；或都用路由器 DHCP）
2. Micro/WIN SMART 里**编译前先分配库存储区**（经典大坑）：
   文件 → 库存储区 → 给 MODBUS_TCP 库分配一段 V 区（如从 VB3000 起，别和 VW0 冲突）
3. 指令树 → 库 → 找到 **Modbus TCP Server**（MBUS_SERVER）指令拖进主程序，每周期调用：
   - 使能 En = SM0.0（常通）
   - 保持寄存器区 HoldReg = 启用；**HoldStart = &VB0**（V 区从 VB0 起映射为 Modbus 保持寄存器）
   - HoldRegCount = 10（够用）
   - 参数含义以软件内置帮助为准——你只要抓住两点：**映射起点 &VB0、数量 ≥1**
4. 下载到 PLC，运行灯正常
5. 验证（先别开我们的系统）：电脑上用任意 Modbus 主站工具（如 Modbus Poll 试用版），
   连 `PLC的IP:502`，unitId 先试 1，读保持寄存器 40001 → 按按钮，值 +1 → **通了再做下一步**

## 方案 2：Modbus RTU（固件 < V2.2，或想顺便演示 485 盒子）

1. 串口 0（RS485）→ 485 转网口盒子（透传模式，TCP→串口）→ 交换机
2. Micro/WIN SMART：拖 **Modbus RTU Slave**（MBUS_INIT + MBUS_SLAVE）两个指令：
   - MBUS_INIT：Mode=1、**Addr=1**（从站站号）、**Baud=9600**、Parity=0（无校验）、
     HoldReg=启用、**HoldStart=&VB0**、HoldRegCount=10
   - MBUS_SLAVE：每周期调用
   - 同样别忘**分配库存储区**
3. 盒子设置：串口参数与上面一致（9600/8/N/1）、TCP 端口如 1503、透传到 PLC
4. 验证：Modbus Poll 连 `盒子IP:1503`、unitId=1、RTU over TCP 读 40001

## 知造 SIRP 侧配置（1 分钟）

设备监控 → 新增设备：

| 字段 | 方案 1（TCP） | 方案 2（RTU 透传） |
|---|---|---|
| 协议 | modbus-tcp | modbus-rtu（透传盒子） |
| 地址 | PLC 的 IP | 盒子的 IP |
| 端口 | 502 | 盒子的 TCP 端口（如 1503） |
| 从站号 unitId | 1（读不通就试 255） | 1（= MBUS_INIT 的 Addr） |

点表（JSON）：

```json
[
  {"key":"cnt","name":"产量计数","address":0,"funCode":3,"dt":"uint16","role":"count"}
]
```

保存后：设备卡片在线 → 点开详情 → **按一下按钮，产量统计的"今日"实时 +1**。
（要自动入库的演示：编辑配置 → 生产入库联动 → 绑一个成品 SKU 和仓库，每件自动进账。）

## 常见坑（都是现场高频）

| 症状 | 原因 |
|---|---|
| 编译报错找不到库存储区 | 没分配库存储区，或和 VW0/其他 V 区冲突 → 挪到 VB3000 起 |
| 连不上 | 电脑和 PLC 不同网段；或防火墙拦 502 |
| TCP 能连读不到 | unitId 不对 → 换 255 再试 |
| RTU 读回来全是错 | 盒子串口参数和 MBUS_INIT 不一致（波特率/校验）；485 A/B 接反 |
| 值一直是 0 | HoldStart 不是 &VB0（比如你映射的 &VB1000，那 address 就该填 500=1000/2）——**映射起点变了，点表 address = 偏移/2** |
| 按钮按一下加好几下 | 没用 EU 上升沿，用了常通 INCW |
