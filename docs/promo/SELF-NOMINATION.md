### ③ 标准简介（200 字，自荐表单「项目简介」字段）

```
知造 SIRP（KnowFab SIRP）是一套面向中小工厂的设备数据与轻量 ERP 系统，一个人独立开发。

它解决的是一个具体的断点：市面上组态软件只做到"能看数据"，云 MES 要上一整套、实施三个月，
而"机器做一件 → 产量涨 → 库存加 → 单据开 → 报表出"这一段，长期没人做。

技术上做了三个刻意选择：全程只读、不改 PLC 梯形图；一个 jar 包内置运行环境与数据库，
不用装 Java、不用装 MySQL、不用 Docker；断网可用，数据不出厂。
已实测接入十余年前的西门子 S7-200，只用一根网线读保持寄存器。

开源 AGPL-3.0，个人自用免费，商业用途需授权。
```

### ④ 完整介绍（600 字，自荐表单「详细介绍」/ 媒体投稿正文）

```
【它是什么】
知造 SIRP 是一套跑在自己电脑上的工厂数据系统，把车间设备的数据接进来，
再往后接到库存、单据和报表。一个人开发，开源。

【为什么做】
我在车间见过太多次：老板问今天做了多少件，班组长说"大概三千多"，仓管翻本子说"账上五千"，
最后谁也不敢拍板。而 PLC 里一直有个寄存器在涨，那个数就是产量——它一直在那儿，只是没人去读。
电气的人知道读哪个寄存器，但不会做界面；程序员会做界面，但不知道寄存器在哪。
我两边都干过，就把这条路打通了。

【解决什么断点】
工厂想看数据，通常两条路：组态软件（组态王/力控/WinCC）能看能报警，几万授权费，
但基本停在"看"；云 MES 功能全，但要上云、按年付费、实施三个月，中小厂扛不住。
中间那一格是空的：机器做一件，产量、库存、单据、报表跟着走。知造 SIRP 补的就是这一段。

【关键能力】
设备接入：Modbus TCP / RTU、OPC UA、串口 485；新机老机都能接，没网口加几十块转换模块。
产量统计：PLC 寄存器里几十万也不清零，按增量算今日产量。
报警：伺服报警码翻中文并给处理建议，台达、三菱伺服内置码表。
大屏：纯网页，浏览器打开就是，24 小时产量曲线，故障原因顶在最上面。
能耗：峰谷平分时电价，还能做基本电费的两种算法对比（按容量交 vs 按需量交）。
ERP：采购、销售、库存、财务、产线、报表，设备产量自动进成品仓并生成生产入库单。
AI：不是聊天框，接了七个数据查询工具，按角色授权；每天早上一份生产日报。

【工程上的三个选择】
一、全程只读，只使用功能码 3 和 2，不写寄存器、不下发指令、不改梯形图。
二、一个安装包，内置 JRE 与数据库，不用装 Java、MySQL、Docker，Windows 一行 PowerShell、
    Linux 一行 curl。客户机不用预装任何东西。
三、断网可用，数据全在本地，不出厂。

【实测情况】
真机接入十余年前的西门子 S7-200，一根网线、只读保持寄存器，产量按增量统计。
其余为系统内置模拟设备，用于演示多设备场景。

【开源与授权】
AGPL-3.0。个人自用、自己厂里用、自己改，都免费；闭源商用、SaaS、白标需商业授权。

【适合谁】
中小工厂（想看清产线但不想花几十万上 MES）、设备集成商与电气工程公司、
电工与维修师傅、想找真实工业场景练手的独立开发者。
```

## 四、必须提醒你的一个真实风险

**你的 git 历史只有 5 天**（2026-10-27 至 2026-10-31，114 个提交）。

审核方一眼看到「项目创建 5 天、114 次提交、2.8 万行代码」，会本能怀疑两件事：

1. 这是不是一个**一次性导进来的代码**（不是长期开发）
2. 是不是**刷的项目**

**这不是你的问题**（你是整理后一次性开源），但它会在审核里扣分。

### 三种应对

| 做法 | 说明 |
|------|------|
| **A（推荐）** | 在 README 开头加一行真实交代：「本项目为个人长期开发，2026-10 整理后开源，历史提交已压缩」——**主动说清，比被发现好** |
| B | 保持持续提交（每周至少几次），让审核时看到的活跃度真实。时间会解决这个问题 |
| C | 不强求推荐位。先把 star、群人数、真实案例攒起来，**下次投的时候材料本身就有说服力** |

**说白了**：这类推荐位对「刚开源 5 天」的项目天然不友好。**再等两周，比现在硬投更划算**——那时你有持续提交、有群友反馈、有真实接入案例。

## 六、投稿被拒后怎么办

**不要改项目，改材料。** 被拒大概率是这三个原因之一：

| 可能原因 | 怎么改 |
|---------|--------|
| 简介太技术，编辑看不懂 | 换成场景描述："老板问今天做了多少件，不用再靠人记" |
| 看不出差异化 | 第一句就写："组态软件只到能看，MES 要定制，中间那段没人做，我补上了" |
| 活跃度不够 | 等两周，攒够提交和 star 再投 |

**注意规则第三条**：一个工作日没消息就是拒了，**不会通知你**。所以投完别等，继续做推广。而且——
**同一个平台不要连续投**，被拒后至少隔一个月再投，否则会被标记。
