# 演示指南（5 分钟把系统"看起来像真厂"）

## 1. 灌演示数据

```bash
python tools/seed-demo.py        # 幂等：重复跑只补缺的，不会刷爆库存
```

它会给系统铺：4 台设备（CNC/注塑/冲床/电表）、2 条产线（装配一线/冲压二线）、
9 种商品、3 仓库、3 供应商 + 3 客户、采购与销售各 7 种状态的单据、
库存 7 类单据、收付款与账龄、45 天历史产量。重复执行不会覆盖你手工改过的编排。

## 2. 登录

地址 `http://127.0.0.1:8080/app/`，默认账号 `admin`，密码见部署脚本输出
（演示环境惯例是 `123456`，**任何正式环境装完先改密码**）。

## 3. 推荐巡览路径（对着客户讲就按这个顺序）

| 步骤 | 页面 | 讲什么 |
|---|---|---|
| 1 | 生产监控 | 设备卡片上的产线徽标（装配一线 #1）、实时状态 |
| 2 | 点开 CNC-01 → 产量统计 | **日表 24 小时 → 月表整月 → 年表 → 综合缩放**，各表之和=顶部 KPI |
| 3 | ERP → 产线管理 → 编排 | 拖动工位、指定成品计数点；"最后一台机器计数=整线产量" |
| 4 | ERP → 采购管理 | 一张订单从草稿到部分入库的进度条；入库单可溯 |
| 5 | ERP → 库存管理 → 单据页签 | 7 类单据同屏；点详情看"来源订单"；作废后库存回滚 |
| 6 | ERP → 财务管理 | 应收应付账龄四档；收款弹窗自动带出未收订单 |
| 7 | ERP → 经营报表 → 导出 | 进销存恒等式"期初+入-出=期末"；Excel 直接能发 |
| 8 | 分析 → AI 助手 | 问"今天各产线产量怎么样"（需在 AI 设置里配 Key） |

## 4. 接真设备演练（无需真设备）

```bash
python tools/modbus-tcp-sim.py       # 模拟一台 Modbus TCP 设备（端口 1502）
python tools/modbus-rtu-tcp-sim.py   # 模拟 485 透传盒子（端口 1503，1/3 号从站）
```

然后到 设备监控 → 新增设备，按[手册 §三](HANDBOOK.md)填地址 127.0.0.1:1502 即可走通
"发现 → 配置点表 → 计数 → 自动入库"全链路。
