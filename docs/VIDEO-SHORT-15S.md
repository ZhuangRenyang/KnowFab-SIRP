## 一句话结构

**真机 → 数字在跳 → 大屏 → 库存 → 一条命令 → 进群**

## 竖屏拍摄/剪辑要点（重要）

### 录屏是横的怎么办

系统界面是 1920×1080，直接塞进竖屏会变成中间一条细带。两个解法：

**方案 A（推荐，最省事）**：录屏时**只裁一块区域**
- 用剪映：导入横屏录屏 → 裁剪画面 → 拖动选择「卡片」「大屏顶部」「库存行」这些局部
- 好处：局部特写比整屏更有冲击力，老板一眼看到数字

**方案 B**：电脑端录屏时把浏览器窗口调窄
- 或者用 OBS 建 1080×1920 竖版画布，把浏览器窗口缩到画布内
- 适合要展示完整界面的段落

### 画中画叠化（提升可信度）

```
┌─────────────┐
│  录屏裁切    │  ← 上 2/3，数字/界面
│  （局部）    │
├─────────────┤
│  PLC 实物    │  ← 下 1/3，始终有真机
│  （竖拍）    │
└─────────────┘
```
下半部分全程放 PLC 实物（按钮亮着），观众潜意识里就信了。

### 字幕安全区

竖屏上下会被平台 UI 遮：
- 上方留 15% 空（别放字幕）
- 下方留 25% 空（别放字幕）
- 字幕区在**中间偏下**（大约 55%~80% 高度）

### 封面（重要，影响点击率）

- 方案 1：PLC 实物照片 + 大字「**让所有机器都报产量**」（推荐，和群头像统一）
- 方案 2：系统大屏局部 + 大字「60 秒接入你的老 PLC」
- 封面文字不超过 12 字，手机上一眼能读完
