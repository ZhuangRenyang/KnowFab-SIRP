# 知造 SIRP · 宣传视频分镜脚本 v1

> 目标受众：中小工厂老板 / 设备主管 / 数字化服务商
> 核心主张：**不用改一根 PLC 线，接上就能看见产量、故障和库存**
> 时长：90~120 秒（横屏 1920×1080 录屏 + 实物空镜）

---

## 零、开拍前 5 分钟准备清单

| 项 | 操作 | 验收 |
|----|------|------|
| PLC 在线 | 电脑有线口 = 192.168.10.100，PLC = 192.168.10.1 | 设备监控页「西门子s7-200」在线 |
| 绑定 | 设备已绑「六角螺栓 M8」→ 成品一仓，自动入库开 | 编辑设备能看到绑定项 |
| 目标产量 | 日目标 = 3000 | 卡片显示完成率百分比 |
| 库存基数 | 记下当前成品一仓·六角螺栓 M8 数量 | 后面要对比用 |
| 大屏 | `http://localhost:8080/screen.html` 全屏（F11） | 24 小时轴完整、无遮挡 |
| 浏览器 | Ctrl+F5 强刷一次，清掉旧缓存 | 卡片显示"今日产量" |
| 录屏 | 1920×1080 / 60fps，隐藏桌面图标与通知 | — |

**动手提示**：让一个同事在镜头外每 3~5 秒按一下 PLC 的 I0.0 按键（模拟生产），产量就会实时跳动。

## 镜头三 · 实时：产量秒级跳动（0:30-0:50）

**画面**：设备监控卡片特写 → 手指（鼠标）按下 PLC 按键 → 卡片「今日产量」数字从 6 跳到 7

**口播**：
> 「按一下，产量就跳一下。**今天产了多少，不是月底对账才知道，是每一秒都知道。**」

**字幕**：
```
今日产量 7 件 · 累计 63      ← 今日增量 vs 寄存器累计，分得清清楚楚
日目标 3000 · 完成率 12%      ← 红绿灯
```

**要点**：一定要同时露出"今日产量"和"累计"，这是与其他 MES 的差异点。

## 镜头四 · 大屏：24 小时趋势 + 故障优先（0:50-1:10）

**画面**：车间大屏全景（可拍实物大屏照片 + 屏幕录制）→ 缓慢推近顶部故障横幅 → 底部滚动字幕

**口播**：
> 「挂在车间墙上的大屏：今天的产量曲线，一眼看到哪个小时掉了。**出了故障，原因和处理建议直接顶在最上面**——不用挨个设备查。」

**要点**：

- 展示底部「最新动态」滚动播报

## 拍摄注意（踩过的坑，别再犯）

1. **产量数字要"活"**：录之前先按几下让数字有基数，从 0 开始不好看
2. **大屏别用小窗口录**：1920×1080 全屏，否则 24 小时刻度会挤
3. **库存页要等 5 秒**：自动刷新是 5 秒一轮，赶时间的话就把等待剪掉
4. **别在录制时展示错数据**：日目标设 3000、库存先记基线，避免出现 1% 完成率这种尴尬数字
5. **PLC 按键由画外同事按**：画面里不要出现手忙脚乱
