## 念稿提示（避免 AI 味和口吃）

1. **别念稿**：看完一遍记住意思，用自己的话说。观众听得出来念稿
2. **一句话说错就停 2 秒重说**，剪辑时剪掉——比硬着头皮说完自然
3. **数字咬字要清楚**：「一万三千五百四十二件」这种要慢半拍
4. **重音落在承诺上**：不改 PLC 程序 / 不动现场的线 / 不联网也能用
5. **录两遍**：第一遍顺嘴用，第二遍正式用。不必追求完美，真实比流利重要
6. 结尾**别喊口号**，平铺直叙报群号更可信

## 只有 PLC 和按钮，怎么拍出好东西

手上只有一套真机（S7-200 SMART + 按钮 + 一台电脑），没有机床也没有车间。
**这不是劣势——真机特写比任何布景都可信。** 观众一眼看到实物 CPU、端子排、网线，
就知道这不是 PPT，是真接上了。

### 空镜清单（每个 10~15 秒，分开录，后期剪着用）

| 编号 | 画面 | 拍法 | 用在哪 |
|------|------|------|--------|
| S1 | PLC 整机正面 | 手机怼近拍 CPU 面板（型号丝印、RUN/STOP 灯亮着） | 开场钩子 |
| S2 | 网线插在 PLC 上的特写 | 侧拍 RJ45 口 + 网线，背景虚化 | 镜头二「不动线」 |
| S3 | 手指按下按钮的瞬间 | 侧拍，手指动作要清楚，**录 5 遍**备用 | 开场 + 镜头三 |
| S4 | 按钮指示灯亮起 | 微距，浅景深 | 镜头三叠化转场 |
| S5 | 电脑网口 + 网线 | 拍电脑侧面网口插着线 | 镜头六「一根网线」 |
| S6 | 终端敲一行命令 | 屏幕录制也行，实拍更有说服力 | 镜头六部署 |

### 录制方法（关键，别一口气录到底）

1. **分段录**：每个镜头单独录 2~3 遍，后期剪接。现场环境再差，分段录都能救
2. **手机 + 电脑双机位**：手机拍实物，电脑录屏，剪辑时叠化（切软件界面前后各留半秒实物）
3. **录屏用 OBS 或剪映**：1920×1080，帧率 30+，录浏览器窗口时把鼠标移开
4. **PLC 指示灯别关**：RUN 绿灯亮着 = "设备真在跑"，这是可信度
5. **收音**：手机离嘴 20cm，手机录人声后期配；或用电脑麦克风录旁白单独一条

### 缺机床怎么办（用软件补，不造假）

系统里内置了 4 台**演示设备**（CNC-01 加工中心 / INJ-01 注塑机 / PRESS-01 冲压机 / METER-01 电表），
它们是产品自带的模拟装置，会自己产生数据。

- 拍多设备画面、拍大屏多设备状态、拍"多台设备一起管"的画面 → **用它们**
- 口播说「系统内置了几台演示设备，可以先看效果」→ 诚实且专业
- **唯一真实数据是「西门子s7-200」那一台**（真 PLC），镜头三和镜头五的按键演示都用它

### 一句话原则

> **拍得到的说，拍不到的不说。**
> 老板们见过太多"PPT 里的工业互联网"，一个真实的 PLC 端子特写比十张车间照都有说服力。

大屏「今日产量趋势」里的柱子来自 `prod_hourly`，里面有演示环境灌的历史假数据，
不清的话曲线会很奇怪（不像一天的生产曲线）。

- 系统内置清空接口：`POST /api/reports/purge` 带 `{"confirm":true}`
- **只清产量历史，不动库存单据**——库存单据里的「生产入库」正是镜头五要展示的东西
- 清完产量历史后，PLC 设备会从当前基数重新累计（基准机制，不用清 PLC 寄存器）

**建议**：录之前清一次产量历史，然后**按几下按键**让数字动起来，这样曲线自然又真实。
