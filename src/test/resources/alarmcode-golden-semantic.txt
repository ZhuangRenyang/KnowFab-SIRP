# 报警码字典黄金样本（手写语义断言）
#
# 为什么要两个文件：
#   golden.txt          —— 自动快照（340 主键 + 586 别名 = 926 行），防「意外漂移」
#   golden-semantic.txt —— 手写，防「集体性错误」（所有人都按错的理解改了）
# 快照只能发现「变了」，发现不了「本来就错」。两个都要有。
#   覆盖由快照承担（全量主键 + 全量别名），不变量与语义承诺由本表承担。
#
# 格式（每行一条，# 开头是注释）：
#   <brand> | <查这个key> | <期望known> | <期望name> | <备注>
#
# 「查这个key」= 现场可能送进报警字点位的值（纯数字，或补零/手册裸数字形态）。
# 「期望name」= 我们对现场的承诺（厂家原文），不是 displayCode（那个会变）。
#
# ⚠️ 改动字典时，这张表要一起改；改这张表时，要能说清为什么。
#    门禁会拿它逐条核对 —— 对不上就是字典错了，或这张表错了。
#
# ⭐ 本表的取舍原则（2026-11-05 定）
#   「查不到」是安全失败（显示「未收录，查品牌手册」，维修工去翻手册）；
#   「查错」是危险失败（给出一个看起来很权威的错误含义，维修工照错方向排查）。
#   ⇒ 含义存疑的码，一律改成官方原义或删掉，绝不写「大致意思」。
