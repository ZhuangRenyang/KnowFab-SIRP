知造 SIRP · 电脑接 PLC 不断网工具包
====================================

场景：一台电脑既要用 WiFi 上网，又要用网线连 PLC。
不正确的配法会导致「插上网线就没网」——通常是网关/DNS/跃点打架。

三个文件，双击即用：

  plc-diag.bat   诊断（只读，不改配置）
                 插上网线后运行，自动判断是哪种断网原因
                 （A 默认网关被抢 / C DNS 抢答 / D 代理 TUN），
                 并在目录里生成 plc-diag-日期.txt，可发给工程师

  plc-on.bat     切到 PLC 模式（需要管理员）
                 以太网 → 192.168.0.100/24，不设网关、不设 DNS、
                 跃点 9000（保证 WiFi 优先上网），关掉共享探测绑定，
                 最后自动 ping PLC 验证

  plc-off.bat    恢复上网模式（需要管理员）
                 以太网 → DHCP 自动获取，跃点恢复自动，绑定恢复

默认参数（可改）：
  PLC 地址     192.168.0.1     在 ps1 顶部改 -PlcIp
  电脑地址     192.168.0.100   在 ps1 顶部改 -Ip
  网卡名       以太网          参数 -Name "你的网卡名"

常见坑：
  1. PLC 的 192.168.0.1 和路由器默认网关撞车（192.168.0.1 是最常见的
     路由器地址）。如果插线后是「整个网络都断」，就是这个原因——
     把 PLC 改到别的网段（如 192.168.10.1）。
  2. Clash/v2ray 等开 TUN 模式时，插新网卡会抢路由。先退出代理再试。
  3. 诊断必须在「插着线、且断网正在发生」的那一刻运行，拔线状态下
     什么都查不出来。
