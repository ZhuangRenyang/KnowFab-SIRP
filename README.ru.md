**Пусть станки сами сообщают о выработке — вместо того чтобы рабочие сканировали штрихкоды.**
Сбор данных напрямую с оборудования → подсчёт готовой продукции по линиям → автоматическое
поступление на склад → закупки, склад, продажи и финансы в одном журнале → отчёты →
ИИ-ассистент для всей команды. Работает на **вашем собственном сервере**.
Java 17 + Spring Boot 3 + Vue 3 + MySQL, поставка одним jar. Или **портативная версия**
со встроенными Java и базой данных: компьютер, на котором ничего не установлено, запускается
одной командой.

## Четыре особенности, выросшие в цеху

- **Одна команда, никаких предварительных требований** — в комплекте Java 17 + MariaDB;
  одна строка для Windows или Linux. Без Docker и без установки СУБД, браузер открывается сам.
  Всё лежит в одном каталоге: **скопировали — это резервная копия, удалили — деинсталляция**.
- **Старые станки тоже считаются** — три способа: Modbus TCP по Ethernet, прозрачная передача
  RS-485 и подсчёт по реле + концевой выключатель. Пресс двадцатилетней давности без сетевого
  порта всё равно считает каждую деталь.
- **Выработка сразу становится складским запасом** — каждый импульс попадает в готовую продукцию,
  никто ничего не сканирует. Закупки, склад, продажи и финансы ведут один журнал, поэтому
  «книги не сходятся с фактом» невозможно по построению.
- **Обновления не переносят данные** — страница «Система» → *Проверить обновления* → загрузка и
  проверка подписи → замена jar. База данных остаётся на месте, данные не покидают завод.

## Установка (одна команда)

**Windows** (10 и новее):

```powershell
# Китай (Gitee, рекомендуется)
powershell -ExecutionPolicy Bypass -Command "irm https://gitee.com/ZhuangRenyang/KnowFab-SIRP/raw/main/tools/portable/install.ps1 | iex"

# Международный / резервный (GitHub)
powershell -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/ZhuangRenyang/KnowFab-SIRP/main/tools/portable/install.ps1 | iex"
```

**Linux / macOS (Intel)**:

```bash
# Китай (Gitee, рекомендуется)
curl -fsSL https://gitee.com/ZhuangRenyang/KnowFab-SIRP/raw/main/tools/portable/install.sh | bash

# Международный / резервный (GitHub)
curl -fsSL https://raw.githubusercontent.com/ZhuangRenyang/KnowFab-SIRP/main/tools/portable/install.sh | bash
```

При первом запуске скачиваются **JRE 17 + MariaDB 11.4** (около 130 МБ), дальше запуск занимает
секунды. База использует `127.0.0.1:3307` и никогда не конфликтует с уже установленным MySQL на
3306. Начальный пароль администратора печатается в окне запуска и сохраняется в
`data/initial-admin.txt`.

Другие способы:

- **Docker Compose** (сервер Linux): `git clone`, затем `sudo bash deploy.sh` (в Китае `deploy-cn.sh`)
- **Если MySQL 8 и Java 17 уже есть**: `sudo bash install.sh --db-pass 'ваш-пароль-MySQL'`

## Возможности

- **Подключение оборудования** — Modbus TCP / RTU / прозрачная передача; двойное сканирование
  подсети и slave-id; таблица точек в JSON; подсчёт по реле + концевому выключателю; встроенный
  симулятор, чтобы разрабатывать без железа
- **Производство** — счётчики по станкам (сегодня / месяц / год), четыре графика (день / месяц /
  год / весь период), настройка линий с порядком рабочих мест и точкой подсчёта готовой продукции,
  время сброса для каждого станка (удобно для двух смен)
- **ERP** — закупки (заказ → приёмка → возврат) · склад (остатки / 7 типов документов /
  оповещения / инвентаризация) · продажи (заказ → отгрузка → возврат, жёсткая проверка остатка
  перед отгрузкой) · финансы (дебиторка и кредиторка, платежи, четыре интервала просрочки) —
  у склада ровно один алгоритм, поэтому книги всегда сходятся
- **Отчёты** — обзор бизнеса / движение склада (начало + приход − расход = конец) / статистика
  прихода и расхода / исполнение закупок и продаж; всё выгружается в Excel; у документов есть
  **дата операции**, поэтому поздние записи в конце месяца не попадают в чужой месяц
- **Энергетика** — пообъектный учёт, тарифы пик / полупик / ночь, основная ставка и плата за
  мощность, график мощности за 15 минут с лимитом по договору
- **ИИ** — ежедневная сводка в 07:00 и **ИИ-ассистент для всех**: вопросы о складе, выработке,
  станках, заказах и финансах на естественном языке, с ограничением по роли, через вызовы
  инструментов, а не генерацию SQL; поддерживаются DeepSeek / Qwen / Ollama, функцию можно
  полностью отключить
- **Роли** — четыре уровня: администратор / начальник цеха / бригадир / **продажи** (только склад
  и подтверждаемое количество, без полей себестоимости)
